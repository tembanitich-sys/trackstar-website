# Partner marks

Official logo files supplied by each partner, prepared for the BusRep website. The originals are kept in `original/` folders. Use partner marks only to say which channels and payment methods BusRep supports. Nothing on the site should suggest a partner endorses BusRep.

General rules for every partner mark:
- Use exactly as supplied: no recolouring, outlines, shadows, rotation or stretching.
- Use them only in the ecosystem diagram, or wherever the site states supported channels and payment methods.
- Every payment mark shows at the **same height** (default 20 px inside a 36 px chip). Card scheme rules require that no payment brand looks more prominent than another.

## WhatsApp

Source: WhatsApp Brand Resource Center (2026 assets, Meta), digital RGB glyph.

| File | Use |
|---|---|
| `whatsapp-glyph.svg` | Official green `#25D366` on white or `#F5F7F8`. Use this in the ecosystem diagram |
| `whatsapp-glyph-white.svg` | On navy or dark backgrounds |
| `whatsapp-glyph-black.svg` | Official dark `#111B21`, single-colour contexts only |

The web copies match the originals in shape and colour. The only change is that the fill moved from a CSS class onto the path, so several copies can be inlined on one page without clashing. Do not put the glyph inside an added background shape; it sits in the same neutral icon tile as the other features. Minimum 16 px tall.

## Payments (`payments/`)

| File | Source | Use |
